# نظام دبلجة الفيديوهات بالدارجة — Shopping Net

كتعطيه فيديو (ولا بزاف)، وكيرجع ليك:
- **فيديو نهائي** بتعليق صوتي بالدارجة كيمشي مع الحركة ديال الفيديو + ملف ترجمة SRT
- **تصاور الإعلانات** بجميع المقاسات (Meta فيد / Stories-Reels / Google Demand Gen / YouTube)

## كيفاش كيخدم

```
روابط Drive / دوسي Drive / ملف فيه روابط / رفع فيديو
        ↓
تحميل ← فحص الوضوح ← توضيح (إلا كان مضبب)
        ↓
Gemini كيشوف الفيديو وكيكتب سكريبت بالدارجة مقسم على اللقطات
        ↓
مراجعة فالصفحة (ولا أمر بالدارجة: "قص"، "سرّع"، "بدل الجملة"...)
        ↓
صوت (ElevenLabs ولا Gemini TTS) ← كل جملة كتتحط فاللقطة ديالها ← مونتاج نهائي
        ↓
final.mp4 + final.srt + تصاور الإعلانات (ZIP)
```

## الأوامر اللي كيفهمهم

فكل فيديو كاين مربع "عطي أمر بالدارجة"، ولا أمر واحد لدفعة كاملة:
- **القص:** "قص أول جوج ثواني"، "حيد من 5 حتى 7"
- **السرعة:** "سرّع الفيديو شوية" (1.15×)، "سرّعو بزاف" (1.5×)، "بطّأ شوية"
- **السكريبت:** "بدل الجملة الأولى ودير hook أقوى"، "زيد الثمن 199 درهم فالأخير"، "عاود كتب السكريبت كامل بطريقة مضحكة"
- **الصوت الأصلي:** "حيد صوت الفيديو الأصلي"، "نقصو شوية"
- **التصاور:** "بدل العنوان ديال التصويرة لـ..."

وإلا ماعجبكش التعديل: **↶ رجع للنسخة السابقة**.

## التثبيت على سيرفر DigitalOcean

**1. صاوب Droplet:** Ubuntu 24.04، على الأقل **2 vCPU / 4GB RAM**.

**2. حط المشروع فالسيرفر** (من GitHub ولا scp) وشغّل:
```bash
cd darija-dubbing
sudo bash deploy/setup.sh
```

**3. عمّر الملف `.env`:**
```bash
nano .env
```
- `GEMINI_API_KEY` = المفتاح ديال aistudio.google.com/apikey
- `ELEVENLABS_API_KEY` = من elevenlabs.io ← Developers ← API Keys
- `APP_PASSWORD` = كلمة سر قوية (هي اللي غادي تعطي للخدامة)

**4. عاود شعّل:**
```bash
sudo systemctl restart darija-dubbing
```

**5. حل فالمتصفح:** `http://IP-ديال-السيرفر:8000`

### (مستحسن) دومين + HTTPS
إلا عندك دومين (مثلا `dub.shoppingnet.ma`)، وجّهو للـ IP ديال السيرفر، وثبت Caddy:
```bash
sudo apt install -y caddy
echo 'dub.shoppingnet.ma {
  reverse_proxy localhost:8000
}' | sudo tee /etc/caddy/Caddyfile
sudo systemctl restart caddy
```
Caddy كيدير شهادة HTTPS بوحدو. بلا HTTPS، كلمة السر كتدوز مكشوفة فالشبكة.

### الأوامر المفيدة
```bash
sudo systemctl status darija-dubbing     # واش خدام
sudo journalctl -u darija-dubbing -f     # شوف الأخطاء مباشرة
sudo systemctl restart darija-dubbing    # عاود شعّل
```

## ملاحظات مهمة

**Drive:**
- الفيديوهات خاصها تكون **"Anyone with the link"**، وإلا ماكيقدرش يحملها.
- رابط دوسي Drive كيجيب **حتى 50 فيديو** فالمرة. إلا كانو كثر، قسمهم على دواسي ولا حط الروابط فملف.

**الأصوات:**
- الأصوات ديال المكتبة (Yassine، Ghizlane...) خاصك تزيدهم لـ **My Voices** فـ ElevenLabs قبل ما يخدمو عبر API.
- `gemini:Kore` ولا `gemini:Puck` = صوت Gemini TTS، أرخص بزاف. جربو مقارنة مع ElevenLabs على نفس الفيديو قبل ما تختار.
- تقدر تزيد ولا تبدل الأصوات فـ `VOICES` فالملف `.env`.

**التوضيح:**
- بلا GPU، النظام كيستعمل FFmpeg (تكبير لـ 1080 + توضيح خفيف). كيحسن، ولكن مايقدرش يرجع تفاصيل تلفت.
- إلا كان عندك سيرفر بـ GPU، ثبت `realesrgan-ncnn-vulkan` والنظام غادي يستعملو بوحدو.
- الحل الأحسن ديما: طلب من الموردين الفيديو الأصلي بجودة عالية.

**التصاور:**
- كتتصاوب من أوضح لقطات الفيديو، فابور.
- `AD_AI_POLISH=1` كيخلي Gemini يحسن اللقطة لصورة منتوج احترافية، ولكن كيتخلص وراجع التصاور قبل النشر: الـ AI يقدر يبدل شي تفصيل فالمنتوج.

**الحماية:**
- المفاتيح غير فالملف `.env` فالسيرفر. الخدامة ماكيشوفوهاش.
- `.env` و `data/` ماكيطلعوش لـ GitHub (`.gitignore`).

## التجربة بلا مفاتيح
```bash
MOCK=1 venv/bin/uvicorn app:app --port 8000
```
كيخدم كلشي بصوت تجريبي وسكريبت وهمي، باش تتأكد من التثبيت بلا ماتخلص والو.
